# CHANGELOG

## v1.1（2026-11-04）

**季节锁（同季约束）默认开启**，预估区间从 p10–p90 改为 p5–p95。

### 季节一致性：250 天 → 42 天

贵阳花溪四期同范围同口径重跑（第三地形验证，`docs/validation-3rd-terrain.md` 第 6 节）：

| 指标 | v1.0（无季节约束） | v1.1（同季约束） |
|---|---|---|
| 四期日期 | 1993-10-08 / **2003-02-22** / 2013-09-29 / 2024-10-29 | 1993-10-08 / **2003-11-13** / **2011-11-19** / 2024-10-29 |
| 月份分布 | {2, 9, 10} | {10, 11} |
| 年内日序标准差 | 101.2 天 | **16.2 天** |
| 年内日序最大差 | **250 天** | **42 天** |
| 四期可读覆盖 % | 99.4 / 97.8 / 98.1 / 98.7 | 99.4 / 93.8 / 92.0 / 98.7 |
| 平均可读代价 | — | **−2.5 pp**（最差一期 −6.1 pp，无低于 70%） |

- 季节离散度从**最大差 250 天 / 标准差 101.2 天**降到**42 天 / 16.2 天**，四期落入同一物候区。
- 代价是可读覆盖略降：2012 期从 98.1% 降到 92.0%（−6.1 pp），2003 期从 97.8% 降到 93.8%（−4.0 pp）；其他两期不变。
- 2012 期的选择被季节项翻转：`2013-09-29`（景云量 0.22%）与 `2011-11-19`（景云量 5.00%）综合分只差 0.002，季节偏移（32 天 vs 19 天）决定胜负。放开窗口可换回约 +4.8 pp 推断可读（实测 +6.1 pp）。
- 2003 期跨传感器：从 LT05 换成 LE07（2003 年 L7 仍 SLC-on，无楔形带）；报告已提示跨传感器辐射差异不可用于定量变化检测。

### 新增：同季约束

- `--season-window N`：共同窗口 ±N 天，默认取 `config/default.json` → `selection.season_window_days = 45`；**`--season-window 0` 关闭约束**。
- 窗口中心由初选各期日期的**圆均值**决定（本轮 10-31，日序 304），不引入外部气候分区，任何地区可复现。
- 打分新增季节一致性项（权重 15%，`selection.weights.season`）：中心 1.0、偏移 = 半宽 0.5、≥2× 半宽 0；四项旧权重按比例归一化，不改变相对关系。
- 窗口内无可用低云景时**不静默放开窗口**，而是写入 plan：`cross_season: true`、`cross_season_days`、`fallback_reason`，并同时给出窗口内最优候选与放开窗口后的推断可读收益（用同一次 STAC 检索的候选计算，不下载）。
- 报告新增 "1.1 季节一致性" 节：窗口中心/来源、改前改后日序与标准差、跨季逐期说明、放开窗口收益；`metadata.csv` 新增 `day_of_year` / `season_window_days` / `season_center_doy` / `season_offset_days` / `cross_season`。

### 区间估算 p10–p90 → p5–p95

- 探针：并发 4 路 × 5 轮，每轮打印 `探针 k/5 轮：X MB / Y s = Z MB/s`，单流仅作诊断、不进样本。
- 样本池由「探针轮次 + 最近 5 条校准净吞吐」扩展为「探针轮次 + 最近 5 条校准净吞吐 + 下载期看门狗分块吞吐（每条运行等距最多抽 10 个）」，各样本等权。
- 区间改用 **p5–p95**，`estimate.json` 新增 `speed_lo_mbps` / `speed_hi_mbps` 与 `interval_percentiles`（旧 `speed_p10_mbps` / `speed_p90_mbps` 保留兼容）。
- 看门狗阈值从 p10 的一半改为 **p5 的一半**；`actual.json` → `watchdog.throughput_samples_mbps` 记录全部块吞吐，`report` 时写入 `calibration.json` 的 `block_speeds_mbps`。
- 花溪 v1.1 实测：探针中位 0.18 MB/s，点估计 0.191 MB/s → **539 s**，区间 **348–704 s**，实测 **600 s**（+11.2%，**落在区间内**）。v1.0 同期点误差 +34.0%、区间未覆盖。
- 注意：本轮开工前校准表里的历史记录还没有 `block_speeds_mbps`，分块样本**要到下一轮才真正进池**；本轮误差改进主要来自 p5–p95 与探针时段，不能记在未生效的机制上。

## v1.0（2026-11-04）

### 两轮真实案例的结论

**1) 南平市延平区（闽北山地，2,653 km²，1993/2003/2012/2024）**

- 1993 需 119+120 双轨，同日只能覆盖区界 75.2%（外接矩形 68.8%），缺测约 659 km²；主图如实标缺，不用跨季拼满。
- 2003 期 QA 之外筛查出薄卷云 310 km²（占区界 11.69%），可读覆盖从 64.0% 降到 52.3%；其余三期几乎无变化（49.1 / 93.9 / 99.4%）。
- 用单流探针（0.051 MB/s）预估 6,151 s，实测 1,227 s，**误差 −80%** → 直接促成 v1.0 的探针并发化。

**2) 珠三角核心（广深莞，9,206 km²，1993/2003/2012/2024）**

- 四期可读覆盖 96.1 / 96.7 / 78.8 / 90.2%；2012 期云影多，但仍是真实日期，未拉别日补洞。
- 4 路 × 5 轮并发探针中位 0.177 MB/s，预估点 38.4 min、区间 26.6–50.8 min；as-run 54.9 min（+43.0%），扣除暂停与续跑重读后冷等价 48.8 min，**落在区间内**。
- 2024 期 LC09 单块实测 0.025–0.038 MB/s，连续 3 块低于阈值 0.065 → 看门狗暂停、落盘、续跑成功。

**3) 贵阳花溪（云贵高原湿润区，961 km²，第三地形验证）**

- 四期实际日期 1993-10-08 / 2003-02-22 / 2013-09-29 / 2024-10-29；可读 99.4 / 97.8 / 98.1 / 98.7%。
- 无干季地区**没有退化到“随便挑”**，但**没有季节约束**：2003 落在冬季，日序标准差 101 天 → “同季”预期不成立（详见 `docs/validation-3rd-terrain.md`）。
- 薄卷云仅 2024 期 205 px（0.08 km²）；EST 436 s / 区间 378.6–542.5 s，实测 584.5 s（+34%，超上界 7.7%，区间未覆盖）。

### 教训：几何覆盖 ≠ 可读覆盖

- 选景打分里的“覆盖度”是**足迹并集 ∩ 目标面**，只回答“有没有影像”，不回答“像元能不能用”。
- 延平 1993 的 75.2%、珠三角四期的 100%，都是几何覆盖；真正可读要先扣填充、云、云影、薄卷云，延平 2003 因此掉了 11.7 个百分点。
- v1.0 起，报告第 1 节把两种口径并排列出（区界覆盖% / 可读% / 不可读 km²），验收阈值用可读（`readable_accept = 0.70`），不再用几何覆盖“看过关”。
- 同理，“预估误差”也不能只看 as-run：暂停、续跑、重复读取要单列，冷启动等价另算。

### 其它修正

- **探针并发 1 → 4**：与 `fetch.workers` 同数，4 路 × 5 轮，按轮聚合取中位；单流降级为诊断字段，不进估算。
- **区间估算**：样本 = 本轮探针轮次 + 最近 5 条校准净吞吐，点取中位、区间取 p10–p90，报告强制写区间。
- **闸门语义**：预测不再决定任务是否继续，只用于提醒/分批；停止条件移到运行期看门狗（连续 3 块 < p10 的一半 → 暂停、落盘、退出码 3、可续跑）。
- **看门狗落盘顺序**：先 `np.savez` 再判定，修复“暂停时刚下完的波段没进缓存、续跑重下”的缺陷。
- **薄卷云筛查**：新增 QA 之外的第三道路径，阈值由延平 2003 三斑块标定并写入 config（附来源）。
- **计时口径**：`actual.json` 支持分段（runs）、冷等价、重复读取与缓存重建明细；报告分别展示。
- **出图**：面板标题同时显示区界覆盖与可读率；薄卷云用品红细网点，与云影斜线区分。
